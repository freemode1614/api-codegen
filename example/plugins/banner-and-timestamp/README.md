# Example: banner-and-timestamp hook plugin

A runnable end-to-end example demonstrating two of the three PR3 hook
slots in a single plugin:

- `afterFormat` — prepends a license header + generation timestamp
  banner onto the prettier-formatted source.
- `writeFile` — logs the output path **and** delegates to the built-in
  `Generator.write` so the file still ends up on disk.

The third slot (`beforeEmit`) is exercised in
[`__tests__/generator-hook.test.ts`](../../__tests__/generator-hook.test.ts);
we leave it out of this runnable example so the config stays readable
without pulling in the TS factory.

## Files

- `apicodegen.config.mjs` — exports a `Plugin` (via `definePlugin`) plus
  a full `ApicodegenConfig` (`spec`, `output`, `plugins`). Self-contained
  — runs against the bundled `petstore.json` fixture and writes `api.ts`
  next to this file.
- `petstore.json` — a 2-endpoint OpenAPI 3 fixture.

## Running

From the repo root:

```bash
pnpm exec tsdown                                            # build src → npm/, bin/
node bin/cli.cjs \
  --config example/plugins/banner-and-timestamp/apicodegen.config.mjs \
  example/plugins/banner-and-timestamp/petstore.json \
  --verbose
```

> The example imports `Generator` and `definePlugin` from the local
> built `npm/index.mjs`, so a fresh `tsdown` build is required before
> running.

Expected log line from the `writeFile` hook:

```
[example] writing 765 bytes to api.ts
✓ Generated .../banner-and-timestamp/api.ts (2 endpoints, 0 schemas) 34ms
```

The generated `api.ts` starts with:

```ts
/**
 * Copyright (c) 2026 Acme Corp.
 * SPDX-License-Identifier: MIT
 *
 * AUTO-GENERATED by @moccona/apicodegen — do not edit by hand.
 * Generated at: 2026-10-06T05:00:15.294Z
 */
```

## How it works

1. `bannerPlugin` declares `afterFormat` (prepend a license header
   string) and `writeFile` (log the call, then call `Generator.write`).
2. The default export is a full `ApicodegenConfig` with `spec`,
   `output`, and `plugins: [bannerPlugin]`.
3. `codeGen()` runs through the generator pipeline, calls the
   `afterFormat` hook with a frozen `code` string, then calls our
   `writeFile` hook with a frozen `code` + `output` context.

## Hook snapshot discipline

Every hook receives a deep-frozen context. Trying to mutate
`ctx.code`, push to `ctx.statements`, or reassign fields on `ctx.initOptions`
throws at runtime. See [`../../docs/plugins.md`](../../docs/plugins.md#generator-hooks-pr3)
for the rules.

## Caveats

- **The `beforeEmit` slot is NOT exercised here.** Look at the unit
  tests for a worked example.
- **`tsdown` must be re-run after source changes** — the example
  imports from the built `npm/index.mjs`, not from `src/`. Same applies
  to the ky-adapter and asyncapi-provider examples.
- This example is deliberately not exhaustive. A production banner
  plugin would read the year from `process.env` (deterministic builds)
  and the timestamp from a build-time constant rather than `new Date()`
  (idempotency).
